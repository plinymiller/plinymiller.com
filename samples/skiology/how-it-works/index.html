For the shop and the guest

The slow part was never the skiing.

On a holiday Saturday the door stacks the same work: tell us your boot size, sign a paper, wait while someone walks the wall, then wait again while a binding is set. A party of four turns into a conversation the shop could have had last night. This desk moves that work out of the 8:30 rush.

  1. 01

    Sizes and the waiver happen before the door

    Height, weight, age, ability, boot size, stance, and a signature are on the ticket when it’s booked. The counter stops being an interview. Friday night already knows who is walking in.

  2. 02

    Batch prep is grouped by pickup time

    The board is 7:30, then 8:00, then 8:30. Pull a whole window, don’t hunt one guest at a time while the next three wait. What’s left on Saturday morning is the late book, not the entire day.

  3. 03

    A gear-ready text carries the QR

    When the tech confirms the release, the guest gets a text and the code lights up. They go to the rail, not the back of the sizing line. The desk scans the same code and hands the set off.

  4. 04

    Express drop closes a clean return

    If every piece is in the bin and nothing is hurt, the guest checks it off and the receipt texts itself. Damage, a missing piece, or a late set lands in a short exception list instead of holding the door.

What the guest does

  • Books a window and a package for each person.
  • Sends the body numbers a tech actually uses.
  • Signs once, on the phone, including for kids.
  • Shows the QR when the ready text lands.
  • Drops a complete set without waiting to be checked in by hand.

What the shop does

  • Sees tomorrow grouped by the minute people will arrive.
  • Pulls suggested lengths and boots instead of starting from zero.
  • Confirms a release estimate. The number is not certified until a tech says so.
  • Hands off with one scan. Swaps are still allowed if a boot is wrong.
  • Only talks to the returns that are late, incomplete, or damaged.

The texts, in order

  1. Booked, with the code and the address, as soon as the waiver is signed.
  2. A reminder the day before, so the window is still real.
  3. Gear ready, with the QR, once the set is on the rail.
  4. Picked up, with the due-back time.
  5. A return reminder the morning it’s due, not the minute they walk out.
  6. Closed, with the receipt. A review ask only if the shop turns it on.

They show up in the phone on the reservation. Nothing is sent unless SMS_PROVIDER is twilio and the account env vars are filled in. Miss those and the desk stays in simulated mode on purpose.
